# Tarot Keyword Companion

A single-page, card-by-card guide to the 78-card tarot deck (Major & Minor Arcana).

- One card per page (two-page spread on wide screens), each with keywords, a one-line meaning, a short description and a Yes/No leaning
- Clickable index with search — tap a card name or keyword to jump to it
- Spin wheel to draw a card when you don't have a physical deck
- Every card has its own link, e.g. `#the-tower`

## Run it
It's one self-contained `index.html` — open it in a browser, or publish with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

Yes/No leanings follow common reading convention; cards often read as "maybe" show their leaning.
